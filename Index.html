Link your local folder to your new GitHub repository # (Replace YOUR_USERNAME and YOUR_REPO_NAME with your actual GitHub info) git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git # 6. Push your code to GitHub git push -u origin main
